The RN app consumed these HTTP/SSE responses in the actual iOS runtime. The evidence collector records observations after UI actions and sanitized request counts/durable state; it does not drive the UI or infer a passing result. Counts are cumulative within each explicitly cleared fixture window and must not be summed across cases. The private journal retains before-fix failures as well as reruns.

An active-background case verified the native Home screen before the fixture finished its turn. The server retained work after the subscription ended: later deltas and the terminal event were not delivered to that subscription. After the transition's cleanup reads, there was no sustained two-second background polling. Server-owned Allow/Deny cards produced two acknowledgement POSTs and no client continuation turn.
