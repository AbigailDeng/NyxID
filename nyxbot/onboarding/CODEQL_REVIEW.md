# PR #1 CodeQL review

Reviewed the 37 CodeQL annotations on PR #1 using SARIF analysis `1760076124`
(CodeQL 2.27.0, merge ref) and the corresponding source at `35696535`.
The analysis has additional results outside the PR annotations; this document
covers the 37 findings surfaced on the PR diff.

## Changes

- Four test diagnostics no longer print full OAuth token results or authorization
  URLs. Their original validation still fails for an unexpected result.
- Salt and nonce generation now return OS-generated random values directly.
  The prior zero-initialized buffers were already filled by `OsRng` before use;
  this change makes the randomness explicit. The encryption test checks that
  repeated encryption changes both salt and nonce and still verifies decryption
  with the correct token and rejection with another token.
- The other 31 findings are reviewed false positives. The table records the
  exact source/sink evidence for each dismissal. No query, language or source
  directory is disabled and no severity threshold is lowered.

MongoDB 8.0.28 instance selected through `NYXID_TEST_DATABASE_URL`. The CLI command
ran 1 test, including salt/nonce freshness, authenticated decryption and
wrong-token rejection. All 10 tests passed; none were skipped. The temporary
MongoDB instance was stopped after testing.
